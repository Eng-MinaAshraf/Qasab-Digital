# قصب — React / Next.js recreation

A responsive RTL landing page recreated from the supplied reference screenshot.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

- The supplied screenshot is preserved as `public/reference.jpg`.
- Because the source provided is one composite screenshot, the visible food/store/gallery imagery is cropped directly from that screenshot into `public/images/`.
- Replace those crops with the original source photos when available for lossless, full-resolution production assets.
- All major sections are implemented as real React components and the layout is responsive.
